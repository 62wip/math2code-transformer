# Домашнее задание 2: Генерация кода

## О задании

Это задание организовано в виде соревнования, в котором вы будете состязаться друг с другом за лучшее качество. В нем вам предлагается обучить свой Трансформер с нуля для генерации кода по промпту на [нашем датасете](https://huggingface.co/datasets/SlavaYus/tinysms_qa_12m). Работа с кодом ни чем не отличается от работы с текстом (по крайней мере в этом задании), поэтому все методы, применимые для текста, переносятся и на код.

В этом задании разрешается пользоваться агентами как для ресерча, так и для написания кода. Однако в отчете будет необходимо описать, как именно вы использовали агентов и на что это повлияло в вашем решении.

## Ограничения

Самое главное ограничение заключается в скорости генерации ответов. Все предсказания для тестовой выборки должны генерироваться не больше чем за 180 секунд на одной видеокарте NVIDIA T4 (доступна бесплатно в Google Colab и Kaggle). Это значит, что вы можете оптимизировать как архитектуру модели, так и код для ее инференса.

Чтобы как-то сузить для вас выбор архитектуры, разрешается использовать только модели на основе Трансформера. То есть ваша модель должна иметь энкодер для кодирования текста и декодер для генерации кода.

Строго запрещается использовать любые методы для сбора и создания дополнительных данных для обучения или дополнительных таргетов (например, дистиллировать другие модели).
